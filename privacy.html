Den här versionen använder ingen spårning

ScandiMapData använder i nuläget inga analyscookies, inga annonscookies och ingen egen användarprofilering. Kartdata och statistik laddas som statiska filer från webbplatsen.

GitHub Pages

Webbplatsen publiceras via GitHub Pages. GitHub kan behandla tekniska uppgifter om besök enligt GitHubs egna villkor och integritetspolicy.

Framtida annonser eller besöksstatistik

Om annonser, analysverktyg eller andra tjänster som kräver samtycke läggs till senare ska den här sidan uppdateras och lämplig samtyckeshantering införas innan funktionen aktiveras.
